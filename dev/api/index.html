ForestDataExplorerExample — Module
ForestDataExplorerExample

Download, process and analyse national forest inventory data.

The package exposes a small, country-agnostic API:

  • download_data: download and cache the raw data of a country;
  • process_data: turn the raw data into a tidy table of forest indicators;
  • estimate_growth: fit a sigmoid (Chapman-Richards) growth model;
  • create_report: produce a multi-page PDF report with maps and charts.

Country-specific logic lives in "country plugins" (see AbstractCountry). The only plugin currently shipped is France.

ForestDataExplorerExample.download_data — Function
download_data(; country, force)

Download and cache the raw data needed to analyse the forests of country: the national forest inventory, the administrative borders (national, regional and departmental) and the land cover (forest categories).

Files already in the cache are not downloaded again unless force=true. Returns the cache folder (see data_dir).

Example

download_data(country="France")

ForestDataExplorerExample.process_data — Function
process_data(; country, window, force)

Process the data of country previously fetched with download_data (they are downloaded automatically if missing) and return a table of forest indicators by year, administrative unit and species.

The table has one row per year, level ("country", "region" or "department"), administrative unit and specie (Latin name), with the columns:

ColumnUnitDescription
volm³standing volume of living trees
hahaforest area attributed to the species (basal-area share of the forest area)
vol_ham³/havol / ha
harvested_volumesm³/yearvolume of the trees harvested
mortality_volumesm³/yearvolume of the trees dead of natural causes
mortality_pc%/year100 * mortality_volumes / vol
biological_growthm³/yeargross biological volume increment of living trees
share_bio_growth_harvested–harvested_volumes / biological_growth
n_plots–number of inventory plots where the species was found alive

Flows that cannot be estimated for a year (e.g. before the first re-measurements) are missing. Ratio columns are recomputed from totals at every aggregation level, so to obtain all-species values sum the total columns and recompute the ratios (see ForestDataExplorerExample.summarise).

window pools the inventory campaigns year-window+1:year to reduce sampling noise (the official IGN statistics use 5-year windows). The result is cached; use force=true to recompute it.

Example

df = process_data(country="France")
filter(r -> r.level == "region" && r.region == "Grand Est" && r.year == 2023, df)

ForestDataExplorerExample.estimate_growth — Function
estimate_growth(
;
    country,
    subregion,
    specie,
    variable,
    min_obs
)

Estimate a sigmoid (Chapman-Richards) growth function y(age) = a (1 - exp(-b age))^c for the species specie (Latin name) in country, optionally restricted to a subregion (a region or a department, by name or code).

The model is fitted on the living inventory trees whose age at 1.30 m was measured. variable selects the modelled tree attribute: :volume (m³, default), :diameter (cm) or :height (m). If specie is not an exact Latin name, all the taxa starting with it are pooled (e.g. "Pinus nigra" includes its subspecies). An error is thrown when fewer than min_obs observations are available.

Returns a GrowthModel.

Example

m = estimate_growth(country="France", subregion="Grand Est", specie="Fagus sylvatica")
m(100)                 # expected volume of a 100-year-old beech, m³
culmination_age(m)     # age of maximum mean annual increment

ForestDataExplorerExample.create_report — Function
create_report(
;
    country,
    subregion,
    year,
    filename,
    window,
    cv_threshold
)

Create a multi-page PDF report on the forests of country (optionally restricted to a subregion, i.e. a region or a department) for year, and save it to filename.

The report contains a locator map with the key figures, maps of the indicators by region or department, a map of the inventory plots and of the forest cover, the trends of the main indicators, a comparison of the most variable indicators with the previous year and the average of the five previous years, the species composition, the growth models (estimate_growth) of the main species, a table by species and a methodology note.

Keyword arguments:

  • window: passed to process_data (1 = single-year estimates);
  • cv_threshold: variables whose mean absolute year-on-year relative change exceeds this value are compared with the previous year and the previous five years (default 5 %).

Returns the path of the created file.

Example

create_report(country="France", subregion="Grand Est", year=2023)

Growth models

ForestDataExplorerExample.GrowthModel — Type
struct GrowthModel

A Chapman-Richards growth model y(age) = a (1 - exp(-b age))^c fitted with estimate_growth. The model is callable: m(age) returns the predicted value.

  • country::String: Country of the data.

  • subregion::String: Subregion of the data (empty for the whole country).

  • specie::String: Species requested.

  • taxa::Vector{String}: Taxa (Latin names) included in the fit.

  • variable::Symbol: Modelled variable (:volume, :diameter or :height).

  • params::Vector{Float64}: Parameters [a, b, c].

  • stderrors::Vector{Float64}: Standard errors of the parameters (NaN when not computable).

  • n::Int64: Number of observations.

  • rmse::Float64: Root mean squared error of the fit.

  • r2::Float64: Coefficient of determination of the fit.

  • ages::Vector{Float64}: Observed ages (years at 1.30 m).

  • values::Vector{Float64}: Observed values of variable.

ForestDataExplorerExample.chapman_richards — Function
chapman_richards(t, p)

Chapman-Richards sigmoid growth function y(t) = a (1 - exp(-b t))^c with p = [a, b, c]: a is the asymptote, b the rate and c the shape parameter (the curve is sigmoid, with an inflection point, when c > 1; fits are constrained to c ≥ 1).

source
ForestDataExplorerExample.fit_chapman_richards — Function
fit_chapman_richards(
    t::AbstractVector{<:Real},
    y::AbstractVector{<:Real}
) -> Tuple{Vector, Any, Any, Any}

Fit a Chapman-Richards curve to the observations (t, y) by nonlinear least squares and return (params, stderrors, rmse, r2). Starting values come from a grid search on the rate and shape parameters, with the asymptote solved by linear least squares.

ForestDataExplorerExample.fetch_file — Method
fetch_file(
    url,
    dest::AbstractString;
    force,
    validate
) -> AbstractString

Download url to dest atomically (via a temporary file), unless dest already exists and force is false. Returns dest.

url can be a vector of URLs (a source and its mirrors), tried in order until one succeeds. A download is rejected when it is an HTML page (servers in maintenance often answer with one) or when validate(path) returns false; a cached file failing these checks is downloaded again.

ForestDataExplorerExample.France.add_growth! — Method
add_growth!(t) -> Union{DataFrame, SubDataFrame}

Add to the living trees t their annual relative volume growth g and their annual volume growth per hectare growth (m³/ha/year).

The 5-year radial increment IR5 gives the diameter five years ago, D5 = D - 2 IR5; volume growth is derived assuming V ∝ D^β, with a species-specific β (volume_exponents). Trees whose increment was not measured get the mean relative growth of the trees of the same campaign, species and 10-cm diameter class (falling back to campaign and species, then campaign).
